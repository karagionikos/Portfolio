# Terminal Portfolio

A retro terminal-inspired interactive portfolio website built with pure HTML, CSS, and JavaScript.

Designed with a clean retro aesthetic, typing animations, boot sequences, command history, and autocomplete to create an immersive terminal experience.

This is a personal portfolio.
