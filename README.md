# Terminal Portfolio

A dark, terminal-inspired interactive portfolio website built with HTML, CSS, and JavaScript.

This is a personal portfolio.

## Live demo

[karagionikos.github.io/Portfolio](https://karagionikos.github.io/Portfolio/)

## Features

- **Dark terminal window** — rounded corners, macOS-style coloured window dots, and an orange accent with a soft glow
- **Boot sequence** — a `[SYSTEM]` startup log that types itself out, then clears for the banner
- **Phosphor banner** — the ASCII banner flickers on row by row, like an old CRT warming up
- **CRT touches** — faint scanlines and a glowing block cursor
- **Typing animation** — command output is typed out character by character
- **Command history** — `↑` / `↓` to cycle through previous commands
- **Autocomplete** — `Tab` completes a command
- **Command suggestions** — a typo gets a "Did you mean …?" hint
- **Accessible** — respects reduced-motion settings and works with screen readers
- **Responsive** — works on mobile

## Commands

| Command      | Description                       |
|--------------|-----------------------------------|
| `help`       | List available commands           |
| `about`      | Who I am                          |
| `skills`     | Soft skills, languages and tools  |
| `projects`   | Things I've built                 |
| `education`  | Studies                           |
| `experience` | Work experience                   |
| `contact`    | Email, GitHub and LinkedIn        |
| `resume`     | Open my CV                        |
| `date`       | Show the current date and time    |
| `banner`     | Show the welcome banner           |
| `clear`      | Clear the screen                  |

## Run locally

It's a single static page — open `index.html` in a browser.
